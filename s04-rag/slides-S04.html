Glosario · bloque 2

Antes de comparar recuperadores, fijemos el vocabulario

Embedding / vector

Representación numérica de un texto; permite comparar significado por distancia.

Dense retrieval

Recuperación semántica: busca vecinos cercanos en el espacio de embeddings.

BM25 / full‑text

Recuperación léxica: pondera coincidencias de términos, frecuencia y rareza.

RRF

Reciprocal Rank Fusion: combina posiciones de varias listas, no sus scores originales.

ANN

Approximate Nearest Neighbors: búsqueda aproximada de vecinos para reducir latencia.

Reranking

Segunda pasada que relee pregunta y candidato para ordenar mejor un conjunto corto.

HNSW / L2

HNSW organiza vecinos para buscar rápido; L2 es la distancia usada por este índice.

MRR / gold set

MRR premia aciertos altos; gold set es el conjunto curado de preguntas y evidencia.

p50 / p95

Percentiles de latencia: p50 representa la mediana y p95 una cola lenta.

Regla de lectura: cada método tiene su propia escala; primero se interpreta el orden dentro del método y luego se evalúa con métricas del gold set.

Precisión técnica · septiembre 2026

En AI Search la métrica operativa es L2, no cosine

Concepto general

Cosine ayuda a explicar el ángulo entre embeddings y se usa en muchos motores.

Implementación Databricks

La búsqueda de vecinos aproximados (ANN) usa HNSW + distancia L2. Si los vectores están normalizados, L2 y cosine inducen el mismo ranking.

La métrica ordena candidatos; la calidad real se valida con un gold set del negocio.

Cómo leer un score

Un score sirve para ordenar; su escala depende del método

BM25 puede superar 1,0

Es una función de relevancia léxica sin normalización obligatoria a [0,1]. Crece según coincidencias, rareza de términos, longitud del documento y parámetros del corpus.

Dense y RRF miden otra cosa

En este notebook, dense muestra similitud coseno; RRF calcula una suma de contribuciones por posición. Sus números no representan la misma unidad.

# Interpretación correcta de una consulta bm25 → orden BM25; score=3.4918 dense → orden dense; score=0.7002 rrf → orden fusionado; score=0.0328

Conclusión: estos tres valores sirven para ordenar resultados dentro de cada carril o fusión. Para comparar métodos usamos hit@k, recall, MRR, precisión, latencia y costo sobre las mismas preguntas.

Del ranking a una respuesta controlada

Top‑k

Número de candidatos que pasan desde retrieval al siguiente paso.

Filtro

Restricción por metadata, permisos, fecha, idioma u otra condición de alcance.

Reranker

Modelo o función que reordena candidatos usando la pregunta y el texto completo.

Abstención

Decisión explícita de no responder cuando la evidencia es insuficiente o no aplica.

Cita

Referencia trazable al documento, página, sección o chunk que respalda la respuesta.

Contexto

Fragmentos recuperados que el modelo recibe junto con la pregunta y las reglas.

ACL

Access Control List: lista de control de acceso aplicada antes de recuperar.

Faithfulness

Fidelidad: las afirmaciones deben estar respaldadas por el contexto recuperado.

Top‑k

Más cobertura también significa más ruido

k pequeño

Mayor precisión; puede omitir la evidencia necesaria.

k grande

Mayor cobertura; compite más contenido irrelevante.

Decisión

Ajusta k con métricas, latencia y presupuesto de contexto.

Top‑k es una hipótesis que se evalúa.

Filtros de metadata

Relevante no siempre significa autorizado o vigente

Fuente

Contrato, política o ficha técnica.

Fecha

Solo versión vigente al momento de la consulta.

Región

Lima, provincias o alcance global.

Acceso

El usuario puede recuperar ese documento.

Los permisos deben restringir la recuperación, no solo ocultar la cita después de generar.

Prompt grounded

Glosario · bloque 4

Las métricas responden preguntas diferentes

Recall@k

Proporción de evidencia relevante que apareció dentro de los primeros k resultados.

Precision@k

Proporción de los primeros k resultados que realmente son relevantes.

MRR

Mean Reciprocal Rank: premia que el primer resultado relevante aparezca arriba.

Faithfulness

Qué tanto las afirmaciones de la respuesta están respaldadas por el contexto.

Correctness

Si la respuesta coincide con la respuesta esperada o referencia.

Gold set

Conjunto curado de preguntas, respuestas y evidencia esperada para evaluar.

p50 / p95

Percentiles de latencia para comparar el comportamiento típico y el peor tramo frecuente.

Diagnóstico

Una respuesta incorrecta tiene al menos dos causas

Retrieval

La evidencia correcta no llegó o llegó rodeada de ruido.

context recallcontext precision

Generación

La evidencia llegó, pero la respuesta la contradice, omite o exagera.

faithfulnessanswer correctness

★ diseño de evaluación

Del smoke test al benchmark

Una evaluación robusta estratifica preguntas y mide más de un promedio

Cobertura

Hecho directo, paráfrasis, identificador exacto, multi‑documento y temporalidad.

Negativos

Sin respuesta, ambigua, fuera de permisos, contradictoria y adversarial.

Operación

Recall@k, MRR, precision, faithfulness, correctness, latencia p95 y costo.

Offline antes de desplegar; feedback y drift durante el uso.

El set de 5 casos de hoy es un smoke test ejecutable. Producción necesita más ejemplos por estrato y revisión humana de los casos ambiguos.

Quiz de cierre · pulsa A para respuestas

Comprueba el modelo mental

1¿Qué rompe un chunk fixed-size en medio de una condición?

La coherencia semántica y la recuperabilidad de la regla completa.

2¿Qué estrategia conviene para códigos exactos y paráfrasis mezcladas?

Hybrid: keyword + ANN.

3¿Qué beneficio aporta CDF al índice Delta Sync standard?

Permite sincronizar los cambios de la tabla fuente.

4Si el chunk correcto llegó y la respuesta lo contradice, ¿qué capa falló?

La generación / faithfulness, no el retrieval.

5Si un documento cabe entero y es la única fuente, ¿RAG es la mejor opción?

No necesariamente: el contexto completo evita perder evidencia por chunking o top‑k.

6¿Qué aporta un reranker además de mover el top‑1?

Separa scores entre candidatos; ese gap permite aceptar, abstener o escalar.
